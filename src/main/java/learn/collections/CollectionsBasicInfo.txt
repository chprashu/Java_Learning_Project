
collection framework introduced after JDK 1.2 
before JDK 1.2 java uses Stack, Hashtable, Vector, arrays 
to manipulate the group of objects

Drowbacks which java faced without collection framework.
* inconsitency
* Lack of inter-operability
* No common interfaces


What is collection framework?
    * its an collection of interfaces and classes within the java.util package.
    * Using them we can store, retrive and manipulate the group objects.

advantages of collection framework:
    * Unified architecture
    * inter-operability
    * Reusability
    * Efficiency

Collection key interfaces
1. Collection: root interface of all collection interfaces.
2. List: A Collection that holds elements in order and allows duplicate elements.
3. Set: A Collection that cannot contains duplicate elements.
4. Queue: A Collection designed to hold prior to processing (e.g PriorityQueue, LinkedList when used a queue)
5. Deque: A double-ended queue that allows insertion and removal from both ends.
6. Map:  An interface that represents collection of objects in key and value pair.
