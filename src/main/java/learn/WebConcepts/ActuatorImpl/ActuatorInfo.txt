Actuators: 
    * Actuators are set of APIs present in Spring Boot, Actuator module in the formate of HTTP or JXM endpoints, which can let us to monitor health and 
    manage your application in production level.
    They expose operational information such as application health, matrics, environment properties, 
    log levels, thread dumps and more.

    * Actuator endpoints helps external systems like Kubernetes, Docker, or AWS load balancers to check project health 
    while in production.

    To enable actuator in your project we need to add dependeny in pom.xml:
        <dependeny>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-actuator</artifactId>
        </dependency>
    
    Configurations related to,

    port:
        Default port of actuator: 8080
        We can modify this by configuring port in properties:
            in yaml,
                management:
                    server:
                        port: 8092
            OR
            in properties,
                management.server.port = 8092
    
    Security:
        We can enable or disable the security to authenticate the actuator endpoints.
        in yaml, 
            management:
                secuirty:
                    enabled: true or false
        but from SpringBoot(2.x+) this is removed, actuator endpoints will take spring security HTTP configurations from the project.

    EndPoints Exposure:
        We can externally configure which endpoint should expose through web and which one is not.
        in yaml,
            management:
                endpoints:
                    web:
                        exposure:
                            include: endopoints names like matrics, env, loggers, beans, shutdown, prometheus, etc..
                            exclude:
        * In Spring Boot v(1.x+): all endpoints are exposed through web by default.
        * But Spring Boot v(2.x+ an 3.x+):
            only health, info are exposed through web by default, other endpoints configuration is needed.

For Health Check APIs: 

1. .../actuator/health

    * we can customise which one to show and which one not to show through configuration.
    * to show complete details about every components like redis, kafka, db, configServer, discovery, etc..
        in yaml,
            management:
                endpoint:
                    health:
                        show-details: always 
                        * if its not added it will show only status: UP or DOWN
                        * UP, When all the components health status is UP except diabled component.
                        * DOWN, If any of the component health status is DOWN except disabled component.

    * All the components will be enabled in default, to disbale the Checks
        in yaml,
            management:
                health:
                    redis:
                        enabled: false
                    db:
                        enabled: false
                    kafka:
                        enabled: false
                    diskspace:
                        enabled: false
    
    * To check free space in disk is droping below given threshold, we can make system to show health is DOWN
        for diskspace component.
        in yaml,
            management:
                health:
                    diskspace:
                        threshold: 1MB
        * this configuration shows diskspace component status: DOWN when freespace is droping below 1MB, so that 
        external systems can catch this information and can alert users.
